# 文章发布与归档

文章以 Markdown 文件保存在 `source/_posts`。只有能修改并部署站点源码的人（站主）可以更改归档状态。

归档文章时，在对应文章的 YAML front matter 添加：

```yaml
archived: true
```

重新构建并部署后，该文章及其详情页会从公开站点移除，也不会出现在归档、分类、标签、站内搜索或 RSS/Atom Feed 中。文章源文件仍保留在仓库；取消归档时删除 `archived: true` 后重新构建部署即可。

这是静态 Hexo 站点，因此没有访客可操作的网页归档按钮或写入接口；归档状态只能通过站点源码修改。
